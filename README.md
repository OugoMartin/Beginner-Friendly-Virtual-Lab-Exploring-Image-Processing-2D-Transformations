# Image Processing & 2D Transformations Virtual Lab

A beginner-oriented computer-vision lab exploring foundational image-processing and two-dimensional transformation concepts in a Jupyter notebook.

## Objective
Build practical familiarity with manipulating digital images and understanding how geometric transformations affect image coordinates and visual output.

## Repository contents
- `Beginner-Friendly Virtual Lab Exploring Image Processing, 2D Transformations.ipynb` — primary lab notebook.

## Portfolio value
The project demonstrates notebook-based experimentation, image manipulation concepts, visual inspection, and foundational computer-vision reasoning.

## Reproducibility note
The repository currently contains only the notebook. Review its cells for exact dependencies and input-image requirements. A stronger revision should add a requirements file, documented image sources/licenses, saved before/after examples, and concise run instructions.
